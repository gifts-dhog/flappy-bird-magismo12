# Flappy bird: Magismo

Офлайн-игра для GitHub Pages без базы данных и сетевых запросов. На стартовом экране отображается поздравление «Подарок на пятнадцатилетие Магисмо от Хогвартса Дамблдора» и кнопка «Начать».

## Публикация в GitHub Pages

1. Создайте новый репозиторий на GitHub, например `flappy-raven`.
2. Загрузите **содержимое** этой папки в корень репозитория: `index.html`, папку `assets` и этот README.
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните.
5. GitHub через несколько минут покажет ссылку вида `https://ВАШ-ЛОГИН.github.io/flappy-raven/`.

Не перемещайте `index.html` отдельно от папки `assets`, иначе изображения не будут загружаться.
